# Lauren Kim — Personal Website

A simple static personal site for Lauren Kim, second-year Kinesiology major at the University of Virginia.

## Structure

- `index.html` — page content
- `style.css` — styles
- `script.js` — footer year and active-nav highlighting

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

The site is published with GitHub Pages from the `main` branch.
